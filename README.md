# 주식데이터분석기

Streamlit과 Yahoo Finance 데이터를 이용해 주식 시세와 과거 데이터를 확인하고, 종목별 수익률을 비교하는 웹 앱입니다.

## 주요 기능

- 종목 코드 입력 및 여러 종목 비교
- 기간별(1개월, 3개월, 6개월, 1년) 주가 조회
- 회사명, 현재가, 전일 대비 등락률 표시
- 종가 선 차트와 시가·고가·저가·종가 캔들스틱 차트
- 거래량 그래프와 평균 초과 거래량 강조 표시
- 5일·20일·60일 이동평균선 표시/숨김
- 선택 기간 첫 거래일을 기준으로 한 종목별 수익률 비교
- 매수일과 투자 금액을 이용한 현재 가치 및 수익률 계산
- 역사적 주가 데이터 표 표시

## 실행 환경

- Python 3.10 이상
- 인터넷 연결 (Yahoo Finance 데이터 조회에 필요)

## Windows에서 설치 및 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 가상 환경을 만들고 앱을 실행합니다.

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 Streamlit이 출력한 주소(기본값: `http://localhost:8501`)로 접속합니다.

## 사용 방법

1. 종목 코드 입력란에 Yahoo Finance 티커를 입력합니다. 한국 종목은 예를 들어 `005930.KS`처럼 입력할 수 있습니다.
2. 여러 종목을 비교하려면 쉼표로 구분합니다. 예: `005930.KS, 000660.KS`
3. 조회 기간을 선택하고 **데이터조회**를 누릅니다.
4. 선 차트, 캔들스틱 차트, 종목 비교 탭을 이용해 결과를 확인합니다.
5. 사이드바 수익률 계산기에서 매수 날짜와 매수 금액을 입력합니다.

## 데이터 및 유의사항

시세 데이터는 Yahoo Finance와 `yfinance`를 통해 제공됩니다. 데이터의 정확성, 지연 여부 및 제공 가능성은 데이터 제공처에 따라 달라질 수 있습니다. 이 앱은 정보 확인 및 학습용이며 투자 조언을 제공하지 않습니다.
